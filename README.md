# Geo-Fi Bot 📐📈

**Geo-Fi Bot** — это мощный инструмент для визуализации математических объектов прямо в Telegram. Бот поддерживает построение графиков функций (2D и 3D), визуализацию геометрических фигур, решение уравнений и пошаговый разбор выражений.

---

## ✨ Основные возможности

### 📈 Графики функций (2D)
- **Стандартные функции**: `y = x^2`, `y = sin(x) * exp(-x)`
- **Параметрические уравнения**: `x = cos(t), y = sin(t)`
- **Полярные координаты**: `r = 1 - sin(theta)`
- **Кусочно-заданные функции**: `{ x, x >= 0; -x, x < 0 }`
- **Неявные функции**: `x^2 + y^2 = 25`

### 🧊 3D Визуализация
- **Явные поверхности**: `z = x^2 - y^2`
- **Неявные уравнения**: `x^2 + y^2 + z^2 = 9` (сферы, торы и др.)
- **Квадрики (по ключевым словам)**: эллипсоиды, конусы, цилиндры и др.

### 📐 Геометрия
- Построение фигур: круг, треугольник, прямоугольник, эллипс, многоугольник.
- Вычисление площади, периметра и характеристических точек (центроиды, инцентры и т.д.).
- Геометрические преобразования: сдвиг, поворот, масштаб, отражение.

### 🔢 Алгебра и Анализ
- **Решение уравнений**: `реши: x^2 - 5x + 6 = 0`
- **Производные**: `производная: sin(x^2)`
- **Интегралы**: `интеграл: x * cos(x)`
- **Разбор выражения**: `объясни: (x+1)^3`

## 📚 Справочник по формулам 3D поверхностей

Бот распознает специальные ключевые слова для быстрого построения классических поверхностей второго порядка. Вы можете указывать параметры `a`, `b`, `c` (по умолчанию равны 1).

| Фигура | Ключевое слово | Каноническое уравнение |
| :--- | :--- | :--- |
| **Эллипсоид** | `эллипсоид` | $x^2/a^2 + y^2/b^2 + z^2/c^2 = 1$ |
| **Параболоид** | `параболоид` | $z = x^2/a^2 + y^2/b^2$ |
| **Гиперболоид (1-пол.)** | `гиперболоид` | $x^2/a^2 + y^2/b^2 - z^2/c^2 = 1$ |
| **Гиперболоид (2-пол.)** | `гиперболоид двуполостный` | $x^2/a^2 + y^2/b^2 - z^2/c^2 = -1$ |
| **Конус** | `конус` | $x^2/a^2 + y^2/b^2 - z^2/c^2 = 0$ |
| **Цилиндр** | `цилиндр` | $x^2/a^2 + y^2/b^2 = 1$ |
| **Седло** | `седло` | $z = y^2/b^2 - x^2/a^2$ |

## ✍️ Как писать формулы

### ✅ Как НУЖНО делать:
1. **Операторы**: Используйте `*` для умножения и `^` или `**` для возведения в степень.
   - *Пример*: `y = 2*x^2 + 3*x - 5`
2. **Функции**: Используйте скобки для аргументов.
   - *Пример*: `y = sin(x)`, `y = ln(x^2 + 1)`
3. **Неявный вид**: Можно писать уравнения как есть.
   - *Пример*: `x^2/4 + y^2/9 + z^2/1 = 1`
4. **Несколько графиков**: Разделяйте функции точкой с запятой.
   - *Пример*: `y = x; y = x^2; y = sqrt(x)`
5. **Константы**: Используйте `pi` и `e`.
   - *Пример*: `y = exp(-x) * cos(2*pi*x)`

### ❌ Как НЕ надо делать:
1. **Пропуск умножения**: Хотя бот пытается понять `2x`, лучше писать `2*x` во избежание неоднозначности.
2. **Непарные скобки**: Всегда закрывайте открытые скобки.
   - *Плохо*: `y = sin(x`
3. **Запятые в числах**: Используйте точку как десятичный разделитель.
   - *Плохо*: `y = 0,5*x` (нужно `0.5*x`)
4. **Сложные названия переменных**: Используйте только `x`, `y`, `z` для графиков и `t`, `theta`, `phi` для параметрических/полярных.

## 🛠 Технический стек

- **Язык**: Python 3.10+
- **Интерфейс**: `python-telegram-bot`
- **Символьные вычисления**: `sympy`
- **Математика и алгоритмы**: `numpy`, `scipy`
- **Визуализация**: `matplotlib`
- **3D рендеринг**: `scikit-image` (алгоритм Marching Cubes)

---

## 🚀 Быстрый запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте файл `.env` и добавьте ваш токен:
   ```text
   BOT_TOKEN=ваш_токен_здесь
   ```
3. Запустите бота:
   ```bash
   python bot.py
   ```
